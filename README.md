# 10-barcode-battler

スマホのブラウザで遊ぶ「バーコードバトラー」。バーコードから「シール」の戦士が決まり、CPUと1対1で戦う。家族で遊ぶ前提。
ルールの元ネタ: https://note.com/sakigomyway_5634/n/n61808a7245e5 （今はシール版に作り直し済み）

## 動かし方

ビルド不要の静的ファイル（`index.html` / `data.js` / `engine.js` / `battle.js` / `store.js` / `cloud.js` / `app.js` / `assets/` / `vendor/`）。

- PCで確認: このフォルダで `python -m http.server 8765` → http://localhost:8765/
- スマホで確認: GitHub Pages など **HTTPS** で公開して開く（カメラ読み取りはHTTPSが必須）
- カメラ読み取り: `BarcodeDetector` があるブラウザ（Android Chrome 等）はそれを使い、無いブラウザ（PCのChrome・iPhoneなど）は同梱の ZXing（`vendor/zxing-library.min.js`、Apache-2.0）で読む。どちらもHTTPSが必要。手入力・ランダム生成も使える
- 画像やデータを作り直すとき: `python tools/build_assets.py`（`assets/` と `data.js` を作る）

## ルール

### 有効なバーコード
標準タイプのJAN（13桁＝12桁＋チェックデジット）のうち、**先頭が45・49（日本の商品＝戦士。45と49は同じ扱い）** か **先頭が9784（日本の書籍＝アイテム）** のものだけ。8桁・UPC-A・QR・他の書籍は無効。戦士は先頭9桁（①②と⑤〜⑨。③④は使わない）、アイテムは先頭7桁だけを使う。

### 戦士のシール（先頭9桁のうち ①② と ⑤〜⑨）
| 桁 | 内容 |
|---|---|
| ①② | 45 / 49（同じ扱い） |
| ③④ | 使わない（どんな数字でもよい） |
| ⑤⑥ | キャラ（00〜99）。わんこ大戦争の100体（105体から kamaitachi-spear, dogimine, dachs-fighter, labrador-diver, beagle-scout を除く）。初期能力（HP・ST・DF・DX・特殊の合計は**200〜400**。各最大999）と成長は `artifact/characters.md` |
| ⑦⑧ | キラキラ背景＝キャラの**最初の限界レベル**（手に入れた直後から、この値まで育てられる）。00-24 ベーシック(10)／25-49 レア(20)／50-69 EX(30)／70-84 ハロウィン(40)／85-94 スーパーレア(50)／95-99 レジェンド(60) |
| ⑨ | 属性。0・5=風、1・6=土、2・7=水、3・8=炎、4・9=雷 |

シールは正方形に3層（奥→手前）：キラキラ → 属性エフェクト → キャラ。

### アイテム（9784の書籍）
⑤⑥⑦（000〜999）→ `コード % 68` で68種のどれか。属性・キラキラはなし。武器・防具・アクセサリー（能力アップ・属性変更・状態異常・耐性・無効）と、使い切りの回復薬5種。一覧は `artifact/items.md`。

### 育成
- 1アカウント（家族ごと）で、同じシール（⑤〜⑨が同じ。45と49は同じ、③④は見ない）の戦士は1体。同じバーコードを読むと既存の戦士を呼び出す
- 戦士は、スキャン・ランダム・数字入力の確定（入力欄から離れる／Enter）のあと、**その場で図鑑に登録**される。別ロットの限界Lv+5も、その場で反映される（入力の途中では登録されない）
- 限界レベルは、**キラキラの値から始まる**（ベーシック10 … レジェンド60）。同じシールの**別ロット**（⑤〜⑨が同じで、③④や⑩以降が違うバーコード）で、さらに **+5ずつ（最大Lv60）**。例：ベーシックは 10 → 15 → 20 …、レジェンドは最初から60で別ロットは効かない
- 勝つと、出場した3体それぞれに経験値 30+5×敵の平均Lv、負けても10。限界に達すると経験値は入らない
- 能力（HP・ST・DF・DX・特殊。各最大999）= 初期値 + 成長 × (Lv-1)

### お店（🏪。お金の使い道）
| タブ | 内容 |
|---|---|
| 🛒 今日の品 | 毎日かわる3つ（日付＋家族ごとに固定。固有の強い装備は並ばない）。同じ品は1日1個。値段：装備は格で150／400／900／2,000（アクセサリー×1.15、特殊効果つき×1.2）、回復薬は120〜1,500 |
| 💱 売る | 持ち物を買値の半分で売る。パーティに持たせているアイテムは1個のこる |
| 🏋 修行 | お金で経験値を買う。1XP＝2円（+50XP＝100円／+200XP＝400円）。**1日600XPまで**、限界レベルは超えない |
| 🎒 持ち込み | 薬草+1（120円、最大+2）／経験値ブースト（250円。出場キャラの経験値×2）。**次の試合だけ有効**（試合を始めると使われる。3本勝負ならその全試合） |
| ✨ 見た目 | 称号5種（300〜3,000円。ホームと対戦中の名前の横に出る）、シールの枠4種（ゴールド・こおり・ほのお・レインボー。600〜2,000円。自分のキャラにだけ付く）。強さには関係しない |

お金は、勝つと 50+10×敵の平均Lv（±20%）、負けると10で貯まる。バーコードを集める楽しさをこわさないよう、限界突破（別ロット）はお金で買えない。

### 報酬（対戦のあとの画面）
- 経験値（出場した3体それぞれ。勝つと 30+5×敵の平均Lv、負けても10）→ お金 → アイテム の順に表示
- お金: 勝つと 50+10×敵の平均Lv（±20%）、負けると10（±20%）。家族ごとに貯まる（使い道はお店）
- アイテム: 勝つと12%、負けても3%でドロップ。68種からランダム（弱い装備と回復薬ほど出やすい。固有の装備と全回復薬は出にくい）
- もらったアイテムは「🎒 持ち物」に入り、パーティ編成で各キャラに持たせる。使い切りの回復薬だけ、使うと1個へる

### 戦闘（シングルバトル：同時入力ターン制）
1. **パーティ編成**（👥）: 図鑑から最大6体。**同じキャラ（⑤⑥）は1体まで**、**同じアイテムは1体にしか持たせられない**。アイテムは持ち物から選ぶ（3体以上いれば対戦できる。6体そろうと公式の形）
2. **見せ合い・選出（戦闘前画面）**: お互いの登録メンバー6体が並んで開示される。**開示されるのは姿（シール）と属性だけ**（名前・レベル・アイテム・スキルは非公開）。自分の6体から戦わせる**3体**を選び、**先発（最初に場に出す1体）と控えの順番**を、**制限時間60秒**で決める（▲▼で入れかえ。時間切れはレベルの高い順に自動）。いまの相手はCPU（CPUも相手の姿と属性だけを見て選ぶ）。将来の通信対戦も同じ仕様
   - **キャラの確認**: 自分のカードをタップすると、下の詳細パネルにステータス（HP・ST・DF・DX・特殊のバー）・**経験値のバー**（次のレベルまでの進み具合。限界に達すると MAX）・スキル（優先度つき）・持たせたアイテム・属性を表示。「選ぶ」ボタンで選出（パーティ編成の画面にも「📋 詳細」ボタンがある）
   - **🔎 相性ヒント**（オン／オフ。設定は端末に保存）: オンのとき、自分のカードに「相手の6体に対して有利◯体／不利◯体」を表示。相手のカードをタップすると、その1体に対して ◎有利／▼不利／△撃ち合い／－互角 を表示
   - **属性分布バー**: 相手の6体の属性の数を、色つきバーで表示
   - **円形タイマー**: 残り10秒で赤くなり、音が鳴る。「あいて：選出中…／決定ずみ ✓」を表示（いまはCPUの演出。通信対戦で実際の状態になる）
   - **← もどる**（画面の上と下）: 選出をやめてホームへ。1試合目なら、持ち込み（薬草・ブースト）は返る。3本勝負の2試合目以降は、確認が出て、やめると経験値・お金なし
   - **公開演出**: 両者が決まったら、カードがめくれて**先発だけが表向き**になる。相手の控えは「？」のまま
3. **ターン**: 自分と相手が**同時に**「スキル」か「交代」を決め、一斉に処理する。順番は **交代 → 優先度の高いスキル → DX（行動速度）の高い順**（優先度が同じ場合のみDX。同じDXならランダム）
4. **スキル**（全キャラ共通）: たたかう(優先度0) ／ クイック(+1、威力60%) ／ 特殊技(0、特殊の値で攻撃・防御無視・必中、3ターンに1回) ／ ガード(+3、攻撃を防ぐ・連続不可) ／ 薬草(HP20%、チーム3個) ／ パワーキー(薬草1個、運しだいの大回復) ／ アイテム(持たせた回復薬を1回)
5. たおれたら次に出すキャラを選ぶ。相手の3体を全員たおしたら勝ち
6. **場は常に1対1**。毎ターン「そのまま**継続**してスキルを使う」か「控えへ**交代**」を選べる。交代は相手のどんな攻撃・補助より先に行われるので、相手の得意属性の攻撃を、耐性のある控えで受け止める（受け出し・サイクル戦）ができる
6.5 **🏳 あきらめる**（行動のメニュー、たおれたあとの交代の選択画面にある。確認あり）: 対戦をやめて結果画面へ。**経験値・お金・ドロップはなし**、戦績（勝敗）も変わらない。試合の中で使った回復薬はなくなり、持ち込み（薬草・ブースト）は戻らない。3本勝負では、対戦全体が終わる
7. **行動順タイムライン**: 両者が入力したあと、「①交代 → ②優先度の高いスキル → ③DXの高い順」に並べて見せてから、処理する（相手の行動もここで分かる）
8. **相手の直近の行動**: 相手のカードに、直近3ターンの行動（例：特殊技・たたかう・交代）を表示。自分の控えは、属性色のボールで名前とHP%を表示
9. **対戦中に見える相手の情報**: 姿・名前・レベル・属性・HPの割合・状態異常だけ。HPの実数、持たせたアイテム、薬草の数、特殊技の待ち時間は非公開。相手の控えは、場に出てくるまで「？」
- 属性の相性：炎→風→土→雷→水→炎（有利×1.5／不利×0.5／同属性×0.75）。急所（1/16で×1.5）あり
- 体力 = HPの能力値 × 10。命中は DX の差で決まる。タイミングメーターは廃止（攻撃倍率は固定）
- アイテム：武器は攻撃の属性、防具は体の属性を変えられる。武器の毒（3ターン、毎ターン最大HPの6%）・麻痺（1回休み）。使い切りの回復薬は、使うと持ち物からへる
- 長引くと21ラウンド目から全ダメージが少しずつ増える
- 相手のCPUパーティは毎回ランダム（6体。レベルは自分のパーティの平均±2。アイテムは50%で持つ）

### ☁ 家族クラウド（Firebase）
ホームの「☁ 家族クラウド」。端末をまたいで、プレイヤー・図鑑・お金・持ち物・パーティ・お店の記録を共有する。
- **家族コード**（12文字。例 `k7m2-x9qa-4tzp`）: 「🔗 家族につなぐ」で作る。ほかの端末で「🔑 家族コードで参加」に入れると、同じデータで遊べる。**家族以外には教えない**
- **ユーザーの追加と削除**（ホーム上部）: 「＋ ユーザー追加」で、なまえを入れて増やす。「🗑 削除」で、いま選んでいるユーザーのデータ（図鑑・お金・持ち物など）をすべて消す（確認あり。元に戻せない）。家族クラウドにつないでいれば、**ほかの端末からも消える**。クラウドには「削除ずみ」の印を残すので、古いデータを持つ端末が送り返しても復活しない（印は空のデータ）
- 同期: データを変えると、少しまとめてクラウドへ送る。起動時・画面に戻ったときに、新しいデータを受け取る。同じプレイヤーを2台で変えたときは、**あとで変えた方**が残る
- オフラインでも遊べる（端末に保存し、つながったあとで同期）。「切断」は、その端末だけ（クラウドのデータは残る）
- 仕組み: 匿名ログイン（Authentication）＋ Firestore。家族コードを知っていて、家族に参加した端末だけが、プレイヤーのデータを読み書きできる（ルール：`artifact/firestore.rules`）。設計：`artifact/firebase-plan.md`
- Firebase プロジェクト: `barcode-battler-84ace`（Spark＝無料、東京）。設定は `cloud.js`（ウェブアプリでは公開される前提の値）

### 3本勝負
ホームの「🏆 3本勝負」: 同じ6体で最大3試合、**先に2勝**。試合ごとに選出と先発・控えを決め直す（HPは全回復。使い切りのアイテムは使ったまま）。前の試合で相手が出したキャラには「G1」などの印が付く（読み合いの材料）。試合の合間と結果画面で、**相手のパーティが公開**される（出た試合／出番なし）。経験値・お金・ドロップは、最後に1回

### 書籍アイテムの入手
書籍のバーコード（9784）は、スキャン・ランダム・入力の確定で**持ち物に入る**（同じバーコードは1回だけ）。

## 家族対戦（通信対戦）
- ホームの「🌐 家族対戦」。家族クラウドにつないだユーザー同士が、それぞれの端末で対戦できる（1本勝負／3本勝負）。
- 部屋を作る→待っている部屋の一覧／部屋コードで入る。両端末が同じ版であること（版が違うと入れない）。
- 方式：両端末が同じ状態・同じ乱数の種・同じ入力で `Battle.resolveTurn` を回す（結果は必ず一致）。入力は毎ターン45秒、時間切れは自動で「たたかう」。あきらめる＝相手の勝ち。
- 待っている部屋の一覧には `artifact/firestore.rules` の更新（Firebaseコンソール→Firestore→ルール）が必要。

## マルチバトル（2対2）
- ホームの「👥 マルチ（2対2）」。6体から4体を選び、先発2体が場に出る（控え2体）。CPUとの1本勝負で、ステージ選び・報酬・クリアはシングルと共通。
- 毎ターン、場の2体それぞれが「スキル（こうげきは相手の2体のどちらかをえらぶ）／交代／あきらめる」を決める。エンジンは `multi.js`（`battle.js` のスキル・ダメージ計算を共用）。
- 家族対戦（通信）のマルチは未対応。

## コラボキャラ（🌟 コラボスキャン）
- 42体のコラボキャラ。通常のスキャンとは別のボタン。バーコードの読み取りルール（同じコードは一度きり・別ロットで限界Lv+5・45/49始まり）は通常と同じ。⑤⑥(00〜99)がコラボキャラに対応（超レア1コード・レア2・ふつう3・出やすい4）。
- 画像・ステータス・コード対応は、合言葉で暗号化した `collab.bin` に入っている（`python tools/build_collab.py <合言葉>` で作る。元画像は `ニューキャラクター` フォルダの7枚）。**公開サイトには、画像そのものは置かない**（合言葉がないと読めない）。合言葉を入れた端末にだけ、コラボの戦士が見える。
- 割り当て表は `artifact/collab-table.md`（非公開・自分用）。設定は `tools/collab_data.py`。

## キラキラのルール（2026-10-27 改訂）
| キラキラ | ⑦⑧ | 始まりLv | 能力の倍率（最も高い能力／2番目） | 限界Lv |
|---|---|---|---|---|
| ベーシック | 00-24 | 1 | ×1.0 | 10 |
| EX | 25-49 | 10 | ×1.2／- | 30 |
| レア | 50-69 | 20 | ×1.4／×1.2 | 50 |
| スーパーレア | 70-84 | 30 | ×1.6／×1.4 | 70 |
| ハロウィン | 85-94 | 40 | ×1.8／×1.6 | 90 |
| レジェンド | 95-99 | 50 | ×2.0／×1.8 | 99 |
- 倍率は、そのキャラの**初期能力の大きい順**（1位・2位）に、各レベルの能力へかける。各能力は最大999。
- 戦士の同一性は「キャラ(⑤⑥)＋属性(⑨)」。同じなら、**上位のキラキラで上書き**（バーコード・限界が置き換わる。Lv・経験値・勝敗・限界アップ回数は引きつぐ）、**同等・下位は限界Lv+10**（最大99）。使ったバーコードは再利用不可。
- 旧版の記述（上の表・育成の節）は、この節で置き換え。

## 作った流れ（再現用）

1. キャラ能力: `tools/gen_characters.py`（元は `03-wanko-bigwar` の units.js）→ `artifact/characters.json`
2. 属性エフェクト5種: Gemini（ブラウザ）で生成。プロンプトは `artifact/attribute-frame-prompts.md`。元画像は `artifact/frames/_raw/`、倍率は `artifact/frames/effects.json`（雷だけ拡大なし）
3. アイテム: `tools/make_items.py`（アイコン切り出し・シール化）→ `tools/gen_items.py`（効果を999スケールに変換）
4. `tools/build_assets.py` で `assets/` と `data.js`
5. シールの試作: `tools/make_sticker.py`（`artifact/stickers/`）
