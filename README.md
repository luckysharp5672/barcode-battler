# バーコードバトラー

スマホのブラウザで遊べる、バーコードバトラー風のゲームです。商品のバーコード（JAN 13桁）から戦士の「シール」が決まり、CPUと戦います。

- 戦士：先頭が 45・49 の商品のバーコード
- アイテム：先頭が 9784 の書籍のバーコード
- カメラでバーコードを読み取れます（PCのChrome・Android・iPhone）。数字の手入力や「ランダム」でも遊べます。
- 読み取りには [ZXing](https://github.com/zxing-js/library)（Apache-2.0）を同梱しています。

キャラクター画像は「わんこ大戦争」（[wanko-daisensou](https://github.com/luckysharp5672/wanko-daisensou)）のものを使っています。
